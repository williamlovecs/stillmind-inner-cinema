# Phase 2 — V2 全面 UX 审计

权威报告：[V2 UX 审计](../../design/V2_UX_AUDIT_V3_2026-11-01.md)。审计绑定 V2 `c32d423c4eaa5e3f263d1679bb78eee0fd181fbd`，不是旧 PR 或营销页面。

## 可观察问题

1. 准备路径把推荐、状态、原理、方法与历史同时铺开，390px 长页达到 2551px，主动作失去优先级。
2. 首页、播放器和结束页共享蓝紫渐变、发光圆环、密集边框，颜色代替信息层级。
3. 结束页重复“结束／停止”标题，种子反馈抢占返回出口。
4. 桌面只有中央窄列，移动首屏比例失衡；方法库像功能货架。
5. 练习对象与控制层级不清，复盘统计比真实条目更显眼。

## 必须保留

十二法独立渲染器、观电影可逆视角、真实计时、后台暂停、缺失评分、worse／stopped 中性语义、存储失败可退出、本机收藏／筛选／复盘和数据控制。V3 重建的是表现层与信息架构，不是这些领域机制。

逐屏前后证据见 [09_BEFORE_AFTER.md](09_BEFORE_AFTER.md)。V2 Expo 旧图不冒充同条件对照；本报告没有真实移动设备或辅助技术验证结论。
