# Phase 5 — 六条 JTBD 全旅程

核心闭环：Trigger → Notice → Select Practice → Experience → Reflect → Choose Next Action → Return to Life。下表严格区分用户操作、系统记录、界面展示与本人自报。

## 1. 被批评后想反击

**入口 → 选择**：打开首页，可完全不写原句；需要时展开状态，选择反复重播或冲动；推荐理由可见，也可换法。
**练习 → 反馈**：进入观电影或人称替代；原句保持，用户可切换观看位置或只观看；暂停、停止、跳过反馈可达。
**真实记录**：方法、活动时长、状态和明确反馈；不把视角变化记成“冷静”。
**返回／复用**：结束后回到今天或在真实历史中回看；是否回复由本人在现实决定，系统不宣称已回应或未回应。

## 2. 等待消息时反复思考

**入口 → 选择**：选择“反复想一件事”，无需上传聊天记录或识别对方身份；可采用观电影／觉察。
**练习 → 反馈**：念头可隐藏再恢复、标记可撤销，也可完全零点击；停止不表示失败。
**真实记录**：只有本次练习与自愿 After-check，没有对方意图、关系预测或 AI 人格解释。
**返回／复用**：用户自行决定离开聊天窗口或回到原任务；再次进入看到的是实际练习记录，不是“已放下”。

## 3. 想冲动发消息

**入口 → 选择**：选择冲动状态与登出法；不授予系统阻挡其他 App 的权限。
**练习 → 反馈**：收起触发句、选择暂停窗口和一个现实动作；可以恢复原句、修改选择或停止。
**真实记录**：选择是意向，不是已执行行为；没有“成功没发”“避免争吵”或系统通知已设的假结论。
**返回／复用**：回现实后自行决定是否行动；历史只显示真实练习，不显示行为拦截成果。

## 4. 身体感觉紧张

**入口 → 选择**：选择紧张状态；呼吸改变或身体关注偏好不符合时，路由阻止不适当方法。
**练习 → 反馈**：可自然数息、凝视、内观或改用现实环境；不需要深呼吸、屏息、关注身体或点击。
**真实记录**：记数来自用户点击，反馈来自本人；没有呼吸频率、放松结论或身体扫描数据。
**返回／复用**：更不舒服可停止并得到中性出口；真实身体疗效与设备端辅助体验 **NOT VERIFIED**。

## 5. 想长期练习

**入口 → 选择**：从方法库按目的、时长与路径探索；收藏、详情和既有路径可继续使用，不必每天重新比较全部方法。
**练习 → 反馈**：十二法共享真实计时与停止，方法各自拥有实际交互；较长时长按现有内容变体运行。
**真实记录**：收藏、筛选与真实完成记录分开；完成次数不是意识等级。
**返回／复用**：可从收藏、方法详情或实际记录返回。十二套独立长课程尚未完成，不能把一分钟脚本拉长冒充深度课程。

## 6. 一周后查看实践

**入口 → 选择**：进入 Reflection 查看本机记录、摘要与空状态；可导出或删除。
**练习 → 反馈**：本周只使用真实保存的 Session，停止、完成、worse 与未评分不等价；没有足够数据时不制造趋势。
**真实记录**：本人反馈与系统记录分列；删除后历史与回顾重新计算，导出反映实际数据。
**返回／复用**：下一步是可解释建议，不是人格或疗效故事；长期留存、主动复用与心理效果仍需真人研究。

现有产品路径覆盖空首页、方法库、收藏重载、真实计时练习、历史／复盘、导出、删除失败与成功；主回归覆盖安全、十二法、暂停、后台、停止、After-check、worse、存储失败与离线。完整重载续练、保存重试和部分状态映射未被上述旅程自动证明，见 [08_QA_REPORT.md](08_QA_REPORT.md)，不得用这张旅程表把它们关闭。
