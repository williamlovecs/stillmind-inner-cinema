# Phase 3 — 三套视觉方向与选择

完整证据：[三种视觉方向与选型](../../design/VISUAL_DIRECTIONS_V3_2026-11-01.md)。

## 五屏同条件比较

A 折页路径、B 一间静室、C 生长索引均包含：首页、方法库、观电影、自然数息、结束与反思。三套使用同一中文任务、同一合成对象、同一 1440×960 与 390×844 viewport；共 30 张真实 Chromium 截图，[证据索引](../../evidence/v3/directions/capture-manifest.json)。

不是三张换色概念图：A 以编辑网格和折页组织信息；B 以空间主体和前后景组织观看；C 以编号索引、纸张物件和行线组织方法及回看。自然数息明确无需控制呼吸、无需点击；观电影视角切换只改变构图，原句与事实不变。

## 决策

加权设计评分为 A 88、B 80、C 83，只是内部设计决策，不是用户或疗效评分。最终采用 A 的全站系统、B 的练习空间和 C 的索引节奏，即可回退的“折页静室”。真实截图已人工查看并修正默认链接色、窄屏呼吸对比与孤字换行。
