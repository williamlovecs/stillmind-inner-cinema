基准：`b4cf885eae5105cb1266d82c040f8ecab7e168b9`。修复分支：`fix/audit-session-integrity-20260906`。

这份文件仅保存可公开的产品工程结论，不包含私人聊天、录音、受保护资料原文、参与者记录或密钥。最初审阅是静态代码审阅；本分支补充的测试以 CI 实际输出为准，不把测试文件存在当作通过。

## 关键事实

Web 首页走本地状态识别、规则推荐及离线脚本，主链路没有调用 `/api/cinema`。服务端有 StepFun 生成接口，原生手动观影路径在用户启用 AI 后可调用；原生 direct 路径仍离线。12 种方法和原有素材保留。

评分是自报，不是医学量表。画面变化不是测得用户状态；结束一次练习不是证明有效。即使没有变化、更不舒服或中止，也应能离开，并如实记录。

## 数据兼容

保留 PracticeSession schemaVersion=1 和原有存储键。新增可选 plannedDurationSeconds、durationSource='active-clock'；旧记录不被破坏，也不被推算成真实活跃时长。新 Web 缺失评分/result/reuse/action 保持缺失，不能统计成零、无变化或拒绝。

匿名事件向后兼容旧 native payload，可选 session_id 仅接受随机安全字符；允许 unreported 和 abandoned，但仍拒绝原话/自由反馈及其他额外字段。只用同意在开始时分享的会话计算遥测漏斗；晚同意的反馈不能被混入开始分母。没有分享也不等于用户流失。

## 验证与限制

新增单元测试执行实际会话函数/资格检查/事件 validator，不只验证文档文字。Provider 测试全部模拟，不花用户 token。浏览器 smoke 通过本地生产构建、Node22 CDP、Chrome/Chromium 检查首次边界、缺评分、暂停、中止、URL 拦截、自然60秒结束、更差反馈和存储失败。

完整结果查看本 PR 的 CI。Chromium 自动化不是 iPhone/Safari/微信真机 QA，不是内容授权、医学安全审查或效果试验。语音能力、字体与动效的实际感受仍需设备测试。源资料授权需要权利人的明确确认，内部边界文档不替代许可。
