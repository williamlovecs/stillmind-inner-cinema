## 做得好的部分，必须保留

1. **真实练习底座**：首页可空输入；安全门在自动开始前；计时由 domain clock 负责；后台不自动恢复；停止能直接跳过反馈。
2. **诚实结果**：缺失评分保持缺失；worse 和 stopped 不包装成完成或疗效；保存失败不阻止退出。
3. **十二法真实入口**：每种方法都有独立交互渲染器，不是同一个呼吸球换标题。
4. **观电影基础关系**：同一句话可在角色／观众／见证位置切换，支持键盘方向键、暂停和减少动态效果。
5. **本地数据路径**：方法收藏、筛选、Session 复盘、设置与数据控制已有实现。
6. **产品方向**：短入口与长期自我观察并存，没有用连续打卡或人的价值评分驱动复用。

## 核心诊断

### P0 — 进入路径把“简单入口”变成长问卷

**实际截图证据**：`choose-390.png` 高 2551px，`inner-cinema-entry` 的对应长页更高。首屏之后连续出现状态、推荐、预览、原理、提醒、步骤、进阶库与记录。

**原因**：准备、学习、手动换法和历史同时处在第一视觉层；每个功能单独合理，合起来让开始动作失去优先级。

**V3 决策**：默认推荐只需“为什么是它＋开始”；状态选择和长方法预览放入次级展开；开始前只保留安全、偏好和可选评分，不重复展示整个目录。

### P0 — 视觉语言仍是深蓝紫工程面板

**实际截图证据**：首页、播放器、结束页均有蓝紫发光、渐变按钮、圆环 logo、密集边框和浮层。

**原因**：颜色承担了太多层级；卡片边框代替了信息层级；不同页面重复品牌、 eyebrow、标题、状态和说明。

**V3 决策**：采用暖纸白、矿物墨色与单一陶土色；练习空间用暖灰黑而不是蓝紫；减少徽章、胶囊和装饰性渐变，保留明确焦点与 44px 触控边界。

### P0 — 结束页重复表达同一件事

**实际截图证据**：`inner-cinema-ended-390.png` 同时出现“练习已结束” eyebrow、视觉下“练习已结束”、大标题“练习已停止”；首屏又被前后评分和种子测试反馈占据。

**原因**：场景装饰、状态标题、结果摘要、测试招募、下一步导航没有主从关系。

**V3 决策**：只保留一个状态标题与一段中性解释；默认主出口是返回，评分摘要降为一条事实，复制反馈和再练放进次级操作；worse／stopped 不鼓励重复。

### P1 — 首页桌面和移动端只是同一窄列

**实际截图证据**：1440px 首页内容只占中央狭窄矩形，大量空间没有形成阅读节奏；移动端第一屏则留白与功能入口比例失衡。

**原因**：单一 max-width 容器承担所有宽度，缺少清晰的前景行动与背景说明层。

**V3 决策**：桌面使用不对称双栏：左侧当前行动，右侧一个安静的观看对象／路径信息；移动端回归单列，主按钮优先，历史入口按真实记录出现。

### P1 — 方法库像十二张功能卡，而不是可学习的方法体系

**代码审计**：`MethodLibrary.tsx` 的卡片同时承载级别、收藏、标题、副标题、摘要、时长、证据层、脚本数和详情链接；筛选也是整张大卡。

**影响**：用户难以快速比较“何时用／要做什么／多久”， twelve methods 被理解为功能货架。

**V3 决策**：采用编辑式索引；每行只突出名称、目的、时长和进入，收藏靠近名称；筛选成为轻量工具行；路径与全方法目录分组但不互相争夺。

### P1 — 练习播放器仍有重复导航和过强界面感

**实际截图证据**：观电影播放器有品牌头、回到入口、方法名、时间、暂停、停止、场景 meta、指导、三个视角按钮与底部提醒。

**保留**：暂停／停止、当前方法、真实时间、同一句话、可逆视角切换。
**改变**：品牌退位，只保留练习名／时间／暂停／停止一条工具行；视角按钮表达“近一点／退远一点／再远一点”的语义，不另加冗余 meta；画面以对象和空间为主，不以装饰网格为主。

### P1 — 复盘与设置的信息密度需要收敛

**代码审计**：复盘先显示三个统计卡，再显示线索、下一步和记录；设置以多层 surface 分割每个控制。数据语义真实，但“本周表现”视觉上比个人记录更强。

**V3 决策**：复盘以记录列表为主，摘要做成轻量一行；没有足够数据就只解释缺失，不生成周趋势；设置按练习偏好、隐私、数据三组，危险操作隔离且结果明确。

## 逐屏重构范围

| 屏幕 | 当前主要问题 | V3 目标 |
|---|---|---|
| 首次打开／首页 | 功能面板感；桌面窄列；品牌过强 | 一个默认下一步，温暖的编辑式空间 |
| 状态／原句输入 | 与多个设置并列 | 可展开、可跳过、明确本地与语音边界 |
| 练习准备 | 2551px 长页；推荐与十二法同时出现 | 一屏一个决定；开始始终清楚 |
| 练习中 | 控制与装饰重复 | 一个注意对象＋固定必要控制 |
| 观电影 | 蓝紫场景和网格分散注意 | 同一原句的前景／背景／距离关系；减少动态等价 |
| 其余十一法 | 独立但视觉语言不统一 | 不同参与强度，共享安静练习壳 |
| 方法库／详情 | 卡片货架、标签过多 | 可扫描索引，目的／方法／路径分层 |
| After-check | 可选但仍有多层卡片 | 跳过优先，评分和补充反馈有明确主从 |
| 结束 | 状态重复、种子反馈抢占 | 中性结束、真实摘要、明确返回 |
| 历史／复盘 | 统计比原始记录更显眼 | 真实记录优先，不制造洞察 |
| 设置／隐私 | 多层边框、控制密集 | 三组清晰设置；导出／删除语义可验证 |
| 异常恢复 | 功能强但提示视觉不统一 | 统一 inline 状态，退出不被保存或网络阻塞 |

## 验收门槛

- 不是“换色通过”：首屏、准备页、方法索引与练习空间的 DOM／布局均需实质变化。
- 320px 主流程无横向溢出；大字号不隐藏停止／跳过；键盘焦点可见；Reduced Motion 不丢内容。
- 十二法仍由相同 method IDs 和 domain clock 驱动；切换方法不绕过安全／偏好限制。
- 原句不变，未答不补值，停止不等于完成，worse 不推荐立刻重练。
- 不把新视觉截图当成真人效果、真实手机、屏幕阅读器或微信验证。
