# StillMind Design System V3 — 折页静室 / Still Room

状态：生产实现规范；对应 V3 独立分支。
范围：A｜沉寂小我的 Next Web 与 Expo 表现层，不包含 B／C 与独立官网。

## 1. 设计原则

- **一个屏幕，一个决定。** 默认路径只要求开始；状态、原句、时长与偏好按需展开。
- **先给注意对象，再给界面。** 练习对象不表示心理效果，也不靠粒子、环形分数或无限动画制造参与感。
- **把事实写得轻而清楚。** 未填就是未填；停止不是完成；保存失败不阻塞退出；动画改变不等于感受改变。
- **退出是普通能力。** 暂停、停止、跳过、替代方式与返回不和主按钮争夺注意力，但始终可达。

## 2. 色彩与材质

| 语义 | Web token | 用途 |
| --- | --- | --- |
| Paper | `#F4F1E9` | 全站阅读底色 |
| Raised | `#FAF8F2` | 输入与少量抬升表面 |
| Sage wash | `#E7EAE0` | 次级选择、静态注意场 |
| Mineral ink | `#282E29` | 正文与主要控件 |
| Muted ink | `#646B60` | 解释文字，保持可读对比 |
| Sage | `#65735E` | 辅助状态与自然对象 |
| Terracotta | `#A9563D` | 主行动、当前选择，唯一强调色 |
| Hairline | `#D4D2C5` | 分隔而非层层描边 |
| Cinema | `#252A26` | 仅练习观看空间 |

不使用蓝紫渐变、多色发光或每段独立投影。纹理只来自低对比纸面线条与几何物件，不依赖外部图片。浅／深语义在共享 design tokens 中同步；Expo 不额外发明调色板。

## 3. 字体与排版

- 中文正文：系统宋体／宋体回退用于大标题，系统黑体用于正文与控件；不下载或提交未授权字体。
- 大标题：`clamp(2.25rem, 5vw, 4.9rem)`，字重 500，行高 1.12–1.25，中文按词组换行。
- 正文：16–18px，行高 1.75，阅读宽度约 34 个汉字；辅助说明不低于 12px。
- 小标签采用句首大写或中文短句，不用全大写英文堆叠；数字启用 tabular figures。
- 页面标题是语义 h1；对话框、练习与结束不重复展示同义标题。

## 4. 网格与空间

- 内容最大宽度 1240px；桌面左右边距 40–64px，移动 20px，320px 最小边距 16px。
- 首页桌面：行动列约 1.05fr，观看对象列约 0.95fr；移动为单列，主行动先于解释。
- 方法库：索引行而非三列卡片；名称／目的／时长有稳定列，移动折成两行。
- 练习：工具行＋时间线＋注意对象＋当前引导＋必要操作；不出现第二套品牌头。
- 触控目标至少 44×44 CSS px；控件距离至少 8px。长中文可换行，不用截断隐藏停止、评分或反馈。

## 5. 组件

### Header

方形折页标记＋字标，保留首页链接与当前栏目。普通页面可有方法库／复盘；练习中只保留必要返回，不重复品牌与宣传。

### Action

主按钮为陶土实色、10px 小圆角；次按钮为透明或纸面，危险操作独立分组。有 hover、active、disabled 与 2px 可见 `:focus-visible`，不使用缩放位移替代状态文案。

### Fold / details

输入、评分、偏好、长预览与补充反馈使用原生展开；未展开不表示必填，也不丢失已选值。展开后不自动开始、不自动同意。

### Notice

行内展示错误、存储失败、安全边界和中性结果；不用 toast 覆盖练习，也不让保存失败困住用户。

### Method index

一行只回答“叫什么／何时用／多久／怎么进入”。证据层与脚本数移到详情，不当作营销徽章。

### Session summary

结束只显示一个状态标题。评分摘要用事实行；复制反馈、再练和测试入口为次级操作。worse／stopped 不推荐立即重练。

## 6. 观电影空间

- 同一原句始终保留，宽屏比例变化对应角色／观众／见证，文字本身不自动改写。
- 前景纸幕、座椅和地面线构成深度；无星空粒子、蓝紫光束或自动运镜。
- “近一点／退远一点／再远一点”由用户主动选择，可用方向键、Home、End；暂停时不可切换。
- 时间推进只改变指导，不替用户选择观看位置，不宣称已经达到觉察。
- Reduced Motion 保留三种静态构图，去除过渡而非删除内容。

## 7. 动效与转场

- 控件反馈 120–180ms；构图过渡 240–360ms；只动画 `transform` 与 `opacity`。
- 不用呼吸球驱动全局节奏，不用完成礼花，不用循环漂浮文字。
- `prefers-reduced-motion: reduce` 下关闭非必要动画、平滑滚动和转场，练习真实计时与操作不变。

## 8. 可访问性与验证边界

- 语义标题、导航、按钮、fieldset、label、aria-pressed 与 live region 保持；不能用可点击 div 替换按钮。
- 键盘焦点使用墨色／陶土高对比外框；观看空间内使用暖纸外框。
- 320px 不横向溢出；浏览器大字号下允许页面滚动，不把控制裁切。
- 自动浏览器尺寸、焦点、对比与 DOM 检查不是完整无障碍审计。真实触摸、iPhone／Android、屏幕阅读器、微信浏览器：`NOT VERIFIED`，直到实际执行。

## 9. 对应实现

- Web：`src/app/experience-v2.css`（沿用文件名避免无关路由 churn，内容为 V3 tokens）、`globals.css`、`page.tsx`、`reset/page.tsx`、`ResetPracticePlayer.tsx`、`observer-cinema.css` 与产品组件。
- Expo：`mobile/src/constants/theme.ts`、`components/stillmind/ui.tsx`、入口／方法库／练习组件。
- 共享语义：`packages/design-tokens/src/index.ts`。
- 测试选择器与既有按钮文本不因纯视觉重构改变；domain clock、attempt、storage 与安全路由不由 CSS 或场景组件接管。
