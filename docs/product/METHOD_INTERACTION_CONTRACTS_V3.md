# StillMind V3 — 十二种方法 Interaction Contracts

基线：`c32d423c4eaa5e3f263d1679bb78eee0fd181fbd` 的真实渲染器与 `METHOD_SYSTEM.md`。
目标：重构体验，不把方法本意换成动画或小游戏。下表“后果”仅指当前交互可确认的后果，不是疗效。

## 共享合同

- 系统按 domain clock 推进指导与真实时间；后台暂停，回来由用户继续。
- 用户主动开始；安全门和偏好不合格时不自动开始。暂停、停止与退出始终可用。
- 主动选择只改变本次界面指导或记录明确标记；不自动写入“已平静／已觉察／已行动”。
- 停止进入可跳过 After-check；未评分保持缺失；worse 不推荐立即重练；保存失败仍允许离开。
- 原句、昵称、事实与回应均不偷换；不要求真实姓名、创伤细节、和解、呼吸改变或身体关注。
- 自动验收：逐法进入、操作、暂停／继续／停止、After-check、记录与再进入；窄屏／键盘／Reduced Motion。人工验收：实际查看代表画面、长文与状态一致性。真人效果与真机／读屏不在自动测试结论中。

## 1. 观电影法 `inner-cinema`

**做什么／看到什么：** 把一句触发或中性对象放在纸幕上，在角色、观众、见证三个观看位置观察同一句话。前景纸幕、座位与地面线表现距离。
**操作与后果：** 可不操作；点击“近一点／退远一点／再远一点”只改变构图与对应提示，原句不变。键盘可切换。
**系统／用户边界：** 系统推进当前引导，不自动替用户切换观看位置；是否靠近或退远由用户决定。
**退出／禁止虚构：** 暂停禁用切换；停止保留原句，不用银幕缩小代表念头消失或觉察达成。
**验收：** 三个位置的原句逐字一致、构图变化、aria-pressed 与方向键正确；320px 可滚读长句；减少动态时等价静态构图；暂停与停止仍真实。

## 2. 呼吸法 `paced-breath`

**做什么／看到什么：** 自然呼吸，呼气时可在心里数一次；静止水面或纯文字任选。
**操作与后果：** 无需点击；轻点只增加本次记数，“重新数”清零，切换呈现不伪造检测。
**系统／用户边界：** 系统提供与时间一致的指导，不测量呼吸频率；是否改变呼吸由用户在舒适范围决定。
**退出／禁止虚构：** 不憋气、不强迫节奏；不舒服改纯文字或停止；水面静止不能声称与呼吸同步。
**验收：** 可完整不点击结束；记数只来自点击；暂停不增加；文字替代完整；无“检测／同步／稳定率”。

## 3. 觉察法 `thought-watching`

**做什么／看到什么：** 看见一句念头是念头，而非命令；可编辑、标记注意、暂时隐藏再查看。
**操作与后果：** “注意到了”只记录主动标记并可撤销；隐藏只改变可见性，不删除或宣布念头消失。
**系统／用户边界：** 系统不改写事实、不判断念头真假；内容与是否标记由用户决定，均可留空。
**退出／禁止虚构：** 不需要让气泡消失；不把次数解释为觉察水平；不适可停止。
**验收：** 空输入中性；长句完整；标记可逆；隐藏后再看保持原文；暂停禁用输入；无自动效果文案。

## 4. 凝视法 `wide-gaze`

**做什么／看到什么：** 轻松观看烛光中心、物体边缘或周围空间，允许眨眼和放松。
**操作与后果：** 可不点；选择范围改变物体构图和提示；“走神了，回到烛光”回中心并记一次主动返回，不是成绩。
**系统／用户边界：** 系统不检测注视；视角由用户选择，不随计时自动切换。
**退出／禁止虚构：** 眼睛不适停止或换法；火焰动画不是注意稳定证据。
**验收：** 三种构图、返回计数、暂停禁用、Reduced Motion 静止；无注视检测或稳定评分。

## 5. 内观法 `body-scan`

**做什么／看到什么：** 选择脚底、手掌、椅子接触点或肩颈，阅读当前感受提示；可改看周围环境。
**操作与后果：** 只改变当前注意位置的文字；没有身体数据。环境替代不要求内感受。
**系统／用户边界：** 系统不判定紧张／放松；用户可不选、跳过不适位置或完全避免身体关注。
**退出／禁止虚构：** 不宣称扫描到身体状态，不把特殊感觉当目标。
**验收：** 四落点、环境替代、44px 目标、禁用身体偏好时路由限制仍有效；暂停与停止可达。

## 6. 人称替代法 `person-shift`

**做什么／看到什么：** 原句保留；另用昵称／代称和“注意到”形成旁观表达，自己填写事实与可选回应。
**操作与后果：** 输入只生成对应的语言框架与回显，不保存为已完成行动，不改原句。
**系统／用户边界：** 所有事实、名字与回应由用户输入；系统不补写经历，不强迫改用第三人称。
**退出／禁止虚构：** 可全留空只在心里试；不能把“考虑回应”说成已经执行。
**验收：** 原句逐字保留；空名有中性回退；长中文不溢出；事实和回应明确为本人输入；暂停与停止。

## 7. 登出法 `logout-pause`

**做什么／看到什么：** 暂时收起触发句，选择何时再决定与暂停期间一个现实动作。
**操作与后果：** 收起改变当前显示；时间和动作只是用户的选择，不控制其他 App、不声称行为已发生。
**系统／用户边界：** 系统提供延迟提示，不替用户决定何时回复；用户可以不返回或不安排动作。
**退出／禁止虚构：** 不是麻木或永久逃避；不伪造提醒已设置或任务已完成。
**验收：** 原句收起／恢复一致；选择可改；结果文字仅记录选择；暂停、停止与离线可用。

## 8. 宽恕法 `release`

**做什么／看到什么：** 先选择边界：暂不处理、保持距离、只停止本次重播；主动选择后才进入观察反应的引导。
**操作与后果：** 只改变本次引导；从“愿意继续”可退回“暂不接触”。
**系统／用户边界：** 系统不主动推断可宽恕、可联系或可和解；只有用户明确选择才展开当前练习。
**退出／禁止虚构：** 不原谅也是有效选择；不淡化损害、危险与边界，不显示宽恕完成度。
**验收：** 默认非接触；三种边界可逆；主动确认才显示 instruction；无和解压力；停止与 worse 中性。

## 9. 合一法 `open-awareness`

**做什么／看到什么：** 开放地注意声音、身体、念头或空间；静态开放场域或纯文字，不要求找到中心。
**操作与后果：** 可不点；标记只列出主动选择的经验范围，可撤销，不评价质量。
**系统／用户边界：** 系统不把所有经验合成“合一状态”；用户决定标记或不标记。
**退出／禁止虚构：** 高激活不优先；没有安静／连接感也正常；没有标记不等于没有觉察。
**验收：** 多选可逆、纯文字等价、无中心到达动画；路由限制、暂停、减少动态与停止。

## 10. 意识聚焦法 `grounded-action`

**做什么／看到什么：** 从屏幕纸面整体／对象／细节或现实普通物品中选一个小细节观察。
**操作与后果：** 构图切换只改变显示；现实物品名只是自填标签，不调用摄像头、不测量注意力。
**系统／用户边界：** 系统提供缩小注意范围的选择，不替用户判断“真实事实”；用户可选择屏幕或现实对象。
**退出／禁止虚构：** 不需要拍照／权限；不把放大倍率说成聚焦能力；练习本身不是通用任务计划。
**验收：** 三档构图、现实对象可留空、无摄像头请求；320px 输入与停止可用；暂停与退出。

## 11. 稳定法 `trigger-journal`

**做什么／看到什么：** 静止方框、普通一句话或身边静止物品／平稳声音，低刺激地观看。
**操作与后果：** 切换对象只改变提示；没有持续按压，也没有稳定度或“距上次点击”成绩。
**系统／用户边界：** 系统不测量注意稳定；用户自主选择对象与停留。
**退出／禁止虚构：** 视觉不适换现实物品／纯文字或停止；图像静止不能证明心理稳定。
**验收：** 三种模式可逆；对象保持静止；无分数／伪统计；减少动态、键盘和停止可达。

## 12. 意识抽离法 `anchors`

**做什么／看到什么：** 从当前房间、今天、更长时间到更大空间调整构图，再主动回到当前房间。
**操作与后果：** 按钮与 range 只改变几何构图与说明；“返回当前房间”恢复近景。
**系统／用户边界：** 时间可给初始指导，但用户可主动调整；回到现实由用户确认，不把拉远当解离目标。
**退出／禁止虚构：** 不适就回房间、脚底、手掌或停止；不宣称形而上体验或已完成心理抽离。
**验收：** 四档、range 与按钮同步、近景恢复；长文与键盘；暂停禁用；结束仍回到现实选择。

## 完成定义

每一法都必须在 Web 与 Expo Web 的实际渲染器上验证，而不是只在本文件打勾。共享通过不代表十二法分别有人工体验验证；长时长仍按现有内容复用说明披露，不能借 V3 宣称已完成深度课程。
