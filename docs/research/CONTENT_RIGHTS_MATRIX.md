## 每个拟上线脚本使用一行审批单

记录：asset_id、来源ID、文章/页码定位（不贴正文）、当前脚本路径、是否逐字引用/改写、拟展示终端、是否发第三方模型、是否允许收费、许可证明的私密编号、审批人、日期、期限、撤回处理。

许可证明编号为空时就是未确认；真实邮件或聊天证据放私密存储，仅记录编号，不上传公共仓库。最终明确决定只能是：approved-as-is / approved-with-edits / link-only / internal-only / rejected / pending。不能用“informed/supported”证据等级替代版权状态。

## 请权利人分别选择，而不是笼统问“能做App吗”

| 请求范围 | 建议先申请 | 未获答复 |
| --- | --- | --- |
| 少量经审阅的1分钟引导脚本 | 列清具体文本供私下审阅，允许删改 | 不上线相关脚本 |
| 署名与出处 | 名称、链接、展示位置由对方确认 | 不暗示官方联名/推荐 |
| 全文或片段检索RAG | 首轮不申请，默认不做 | 不建供用户检索的正文库 |
| 发送给模型/第三方托管 | 列服务商、字段、用途、保留情况，另行批准 | 不发送受保护材料 |
| 改编、翻译、TTS/音频 | 单独确认每种媒介 | 不从文字许可推定音频/翻译许可 |
| 免费封闭Web内测 | 人数、展示范围、期限明确 | 不把不收费当默认授权 |
| 公开Web、iOS/Android及商业收费 | 第二阶段单独确认地域/期限/费用 | 无公开/商业许可即不作此用途 |
| 终止与更新 | 确认删除/下架、修改复审、投诉联系人 | 不承诺无法执行的即时全网撤回 |

## 发给内容负责人的计划提纲（待发送）

目的：把日常自我观察练习做成短时可交互入口。首轮仅少量经确认脚本、封闭体验，不出售资料，不提供全文阅读或下载，不建立模仿老师人格的机器人。

操作：用户可不输入个人经历，选择状态后做一次短练习，可随时停止，反馈可不填。希望对方审核具体脚本、来源标注和禁止使用内容。未获得明确批准前，不使用相关受保护文字进行分发；公开上架、收费、RAG、翻译/音频另行谈。

不宣称具备诊疗能力或保证觉醒。产品可透明说明来自自我观察/灵性练习的兴趣，但不能暗示权利人已背书、合作或认可效果。

## 发布检查

发布负责人逐一核对所有实际打包脚本/素材到审批记录；不只抽看一本索引。未许可内容先移出发布包或用有明确权利依据的原创内容替代；替代后重跑内容/流程测试。工程check-source-boundary通过只说明结构约束，不解除这个人工门槛。
