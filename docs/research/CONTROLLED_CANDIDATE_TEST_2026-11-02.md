# V3 / V4 主持式可用性测试：3–5位成年人

状态：执行方案，不是已完成的用户研究。真实手机预检目前未执行，用户暂时不能配合。本文不替代原15人协议；这是扩测前的小样本、双候选操作理解检查，不用于疗效、市场规模或付费结论。

## 开始前的闸门

每一项都实际确认后，才邀请和测试：

- 内容负责人确认本轮内容和展示范围有适当许可或可用依据；技术上不接知识库，不代表脚本自动获授权。
- 固定两个候选的完整代码SHA、构建来源、目标URL和表面类型（Web / Expo Web / 原生）。CI通过不代表URL已部署或手机已能打开。
- 用无开发者登录态的真实手机核验可达性、退出/暂停、长文本、数据保存/清除和必要权限。本轮不自动部署、开放公网端口或修改防火墙。
- 确认参与者18岁以上、自愿参加、可随时退出；默认不录音、不录像、不截私人内容。单独获得记录非敏感操作观察的同意，不默认同意上传统计。
- 提供私密反馈方式。真实记录、联系方式与同意凭证不得进入GitHub、公共Issue或本协议的公开模板。

无法完成设备/访问/许可闸门时，状态写NOT RUN或BLOCKED，不填PASS。本轮工程任务不会代替参与者作答。

## 统一情境与非诱导说明

使用同一条合成、低敏感情境，不要求回忆真实冲突或创伤：

> 工作群里有人对一份方案提出不同意见。你有点想马上解释，但暂时不必回复。

主持人开场：

> 今天测的是界面和操作，不是你的心理状态或练习水平。请使用这个虚构例子，不要输入姓名、私人事件或医疗细节。不喜欢、看不懂、不舒服都可以随时停止。我只记哪里犹豫、是否需要帮助和不含隐私的反馈，可以吗？

不说“应该放松”“这个版本更有效”，不讲哪款是新版本，不先教授观众席或间隙理论。产品出现可选评分时可跳过；缺失就是缺失，不代填，不混用不同量表。

## 固定顺序

先锁定顺序，再开始收数据；不根据前一个人的喜好临时挑顺序。

| 匿名ID | 候选顺序 | V3内部方法顺序 |
|---|---|---|
| P01 | V3 → V4 | 观电影 → 登出 |
| P02 | V4 → V3 | 登出 → 观电影 |
| P03 | V3 → V4 | 登出 → 观电影 |
| P04 | V4 → V3 | 观电影 → 登出 |
| P05（可选） | V3 → V4 | 观电影 → 登出 |

3或5人为近似平衡，不宣称严格均衡或随机对照。只完成3人也保留全部结果，不补造人数。方法切换/候选切换间给30–60秒中性休息；记录之前是否见过另一候选和是否得到提示。

## 每人15–20分钟

1. 约2分钟：确认同意、情境、设备与固定版本，不收真实事件。
2. 第一候选约4–6分钟：先看自然使用，不提示按钮位置。记录从看到入口到开始的时间、第一处犹豫和请求帮助。卡住20秒后可给一次中性操作提示，并记录“有帮助”。
3. 中性休息30–60秒，再体验第二候选约4–6分钟。V3尝试观电影和登出；V4尝试间隙。两者自然时长可以不同，本轮不把主观前后分数拿来比较疗效。
4. 自然任务结束后，再单独做功能指令：暂停一次、明确继续、停止或正常结束、找到下一步/记录。指令任务的成功不能反写成首次独立完成。
5. 约3–4分钟非诱导访谈与退出：问清理解、负担、可能再次打开的场景，并按参与者意愿清除其本机记录。

进入方法可经正常方法库选择 `inner-cinema` / `logout-pause`；不要用测试脚本中的activation、eyes、direct参数强行绕过真实舒适偏好或资格检查。若某方法不适合该参与者，就记SKIPPED并尊重替代/停止，不为了凑齐比较强迫练习。

正常完成、主动停止、跳过、看不懂都是真结果。不要让主持人代点击后记为独立完成。发现不适先停止，不追问私人原因；需要现实帮助时退出本工具的测试范围。

## 只记录可分析的操作证据

每位参与者每个候选一行，另记两种V3方法是否尝试。用同目录 `candidate_comparison_results_template.csv` 的空模板，真实副本存私密目录、排除Git。

- 匿名ID、候选顺序、确切SHA、URL、设备/OS/浏览器大类、日期、实际表面类型。
- 首次开始耗时、是否独立开始、实际犹豫位置、提示次数、是否能说明刚才的交互在做什么。
- 暂停/停止/退出是否可找到、结束后是否知道下一步、是否遇到错误保存/删除或隐私疑虑。
- 再次使用选择：V3 / V4 / 两者不同场景 / 都不会 / 不确定，以及非敏感原因。它不是实际留存或支付证据。
- 空白保留空白；未观察写NOT OBSERVED，未执行写NOT RUN，跳过写SKIPPED。不要把未知填0或no。

建议问法：

> 你觉得刚才这个工具在做什么？哪里停下来想了一下？哪个操作有明确作用、哪个像多余按钮？结束后你觉得可以做什么？如果以后再次打开，会在什么情况下？两种都不想用也可以直说。

不收姓名/联系方式/触发原话/诊断，不默认截图或录音。研究笔记和联系人分开保存；事先说明保留期限和撤回方式，默认建议30天内完成整理后删除非必要原始笔记。未获得同意的数据不上传或代填。

## 何时停止、如何决策

任一隐私泄漏、错误记录练习时长、停止/删除失效或明显不适，暂停该候选，先排查再继续。同一开始/理解阻塞在两人重复出现，先做最小修复，不扩样本、不开发V5；修后单列新版本数据。

汇总用“P01在此需要一次提示”等原始观察和分母，不靠3–5人给出疗效、市场规模、显著性、获胜概率或估值。对版本顺序和主持帮助做标注。

可能结论有四种：保留双路线（服务不同场景）、聚焦一款、仅融合一个已验证交互、证据不足继续观察。任何结论都需真实操作记录支持，不让AI根据审美或测试数量替用户选获胜版本。
