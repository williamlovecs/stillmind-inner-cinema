# 《意识强度》语料综合与产品边界

## 1. 覆盖范围与方法

本综合基于用户提供的上下两册 PDF，而不是网络书评或局部摘录。

- 上册：502 页，500 页含文本，156 个 PDF 书签条目，241,276 个提取字符。
- 下册：404 页，403 页含文本，157 个 PDF 书签条目，192,396 个提取字符。
- 合计：906 页，433,672 个字符，源文件 SHA-256 已写入 `corpus/index.json`。
- 逐页文本、页码、页标签、字符数与区块数保存在两个 `pages.jsonl` 文件中。
- 逐页页眉比 PDF 书签页码更可靠。书签用于概念清单，章节边界使用页眉复原。
- 视觉检查覆盖封面、章节起始、四分位正文、练习页、中段页与末页。最后两页为空白页，与文本覆盖统计一致。
- 知识库已抽取 2,118 个概念候选、2,003 个练习上下文、1,734 条主张候选，全部带 PDF 页码。

这些数字证明语料已经被完整处理，但不证明书中任何量化数值或科学主张有效。

## 2. 全书结构

全书把“意识强度”描述为九个空间区域。作为产品原料，它们可分为三个层次：

1. **可观察行为层**：注意、解释、情绪、选择、行动、复盘、关系和适应。
2. **反思隐喻层**：惯性、流动、连接、模块、信息路径等可帮助用户组织经验的隐喻。
3. **来源体系层**：神性、灵性、能量粒子、穴位、植入物、前世和内部几何结构等作者体系中的本体论。

产品可以使用第一层；第二层只能作为明确标注的隐喻；第三层不得包装成科学测量、医学事实、诊断或治疗。

## 3. 九章综合

### 第一章：中央区域 / 心智控制区

**页码**：上册 PDF 9-63，共 55 页。

本章关注自动反应与自主选择之间的差异。可观察主题包括客观自评、反省、接受反馈、问题分析、挑战舒适区、独立判断、身体与自我评价、社会比较和修正行动。

最有价值的工作流是：

1. 发现一个自动反应。
2. 描述触发条件和当时解释。
3. 区分事实、推断和习惯性判断。
4. 生成至少一个替代反应。
5. 行动后复盘结果并修正。

**风险**：书中使用自定义百分比与“意识数值”，并出现 NPC、程序化意识等表述。这些不能成为人格标签或规范化分数。

### 第二章：上方区域 / 自主意识区

**页码**：上册 PDF 64-129，共 66 页。

本章集中在执行与自我调节能力：灵活切换、冷静处理、挫折应对、从沉迷中抽离、共情、独处、独立思考、宏观与细节观察、自我修正、直觉、尊重、信息整理与过滤。

可产品化的不是“强度排名”，而是具体事件中的能力证据，例如：

- 在信息过载时识别当前决策真正需要的事实。
- 在压力情境中延迟反应并记录替代动作。
- 在争议中复述对方观点并检查理解是否准确。
- 事后比较原预测、实际结果和下一次调整。

**风险**：直觉、第六感和非物质信息辨识混在同一体系内。产品只能把直觉视作待验证输入，不能当成事实来源。

### 第三章：下方区域 / 神性连接区

**页码**：上册 PDF 130-225，共 96 页。

本章包含四组内容：安全感、生命支持、生命探索和神性连接。前半部分涉及家庭、社会、人际、亲密关系、金钱、工作、生命和生育安全感，以及稳定、信任、助人、真实表达、好奇、接纳、尊重、热爱和享受生命。

可保留的实践包括电影触发反思、尝试陌生活动、信任边界、真实表达、冥想、注意训练、情绪观察和多角度探索。

**风险**：本章把这些实践与宇宙、命运、神性连接和能量联系起来。产品不得将安全感或生命态度解释为与宇宙连接的测量结果。

### 第四章：右方区域 / 思维扩展区

**页码**：上册 PDF 226-299，共 74 页。

本章关注学习、理解他人、接受新事物、接纳他人、融入集体、影响他人、独立思考和高瞻远瞩。可用内容强调新技能学习、系统分析、创造性方案、多角度决策、共情、组织目标与个人价值的协调。

**风险**：章节使用流行化的左右脑二分、先天设定、智商推断和前世回溯。产品不得据此评估脑区开发、智力、先天能力或记忆真实性。

### 第五章：左方区域 / 旧有惯性区

**页码**：上册 PDF 300-501，共 202 页。

这是全书最适合转化成软件工作流的一章。它区分：

- 思维惯性：传统观念、舆论、教育、家庭、人生阶段和突发事件带来的框架。
- 行为反应惯性：常规、意外、创新和绝望型反应。
- 情绪反应惯性：愤怒、内疚、自责、嫉妒、羞愧、恐惧、焦虑、自卑、悲观、自负和傲慢。
- 模式属性：流动、延展、分化、原发保留、继发形成和诱导影响。

可产品化模型：

`触发 -> 当时解释 -> 情绪/身体信号 -> 默认动作 -> 短期结果 -> 长期代价 -> 替代动作 -> 下次提示`

长期价值来自跨事件聚类，而不是一次性测试：用户在多个决策、冲突或压力事件中是否重复同一解释和动作？替代动作是否真正改变结果？

**风险**：情绪与心理健康敏感主题很多，不能诊断疾病；“洗脑”“催眠波”“植入物”等只能视作来源体系语言，不能确认用户遭到外部操控。

### 第六章：左上区域 / 神经联络区

**页码**：下册 PDF 3-120，共 118 页。

本章按视觉和听觉的采集、传输、存储、回忆来讨论注意盲点、选择性关注、主观信念、情绪和时间带来的记忆变形。它包含隐藏图像、声音关注和描述差异等可交互练习。

适合产品的训练包括：

- 先独立记录观察，再与原始材料对照。
- 分开记录“看到/听到的内容”和“我对它的解释”。
- 延迟后复述，再检查遗漏与新增细节。
- 在同一材料上切换关注目标，观察注意过滤如何变化。

**风险**：章节给出大量无出处的人类平均百分比，并把隐喻描述成神经系统机制。产品应引用独立的认知科学证据，不能沿用这些数值。

### 第七章：左下区域 / 神性交换区

**页码**：下册 PDF 121-218，共 98 页。

本章描述一组身体位置、穴位、能量、粒子聚散、回流和落地。大量内容属于作者的灵性/能量体系。

其中可独立保留的通用实践只有呼吸、冥想、情绪调节、表达练习、专注、灵活思考、自我评估和复盘。应直接解释这些实践的目的与限制，不能声称它们改善书中所述穴位或粒子状态。

### 第八章：右上区域 / 灵性结构区

**页码**：下册 PDF 219-253，共 35 页。

本章以树形、星形、珠线、环线、金字塔和底盘等结构描述信息传输与保护。它可以启发可视化隐喻，如“信息路径”“阻塞”“分流”“连接”，但不能作为用户内部灵性结构的测量。

### 第九章：右下区域 / 模块交换区

**页码**：下册 PDF 254-403，共 150 页。

本章以模块建立、互动、交换和网络路径描述系统整合。它反复用硬件升级、信息流、网络节点和几何运动解释变化。

可产品化的抽象是系统地图：一个决策涉及哪些角色、约束、信息源和反馈回路？哪个连接产生延迟、失真或重复冲突？用户可以重画系统，而不是声称检测到内部几何结构。

## 4. 来源原生内容模式

全书大量条目使用以下编辑模式：

`概念名 -> 特点/定义 -> 影响 -> 例子 -> 量化数据 -> 实操指南/提升建议 -> 区别与联系`

产品可安全改造成：

`反思主题 -> 可观察信号 -> 真实事件证据 -> 可能替代解释 -> 小实验 -> 复盘指标 -> 来源页码 -> 证据提示`

关键变化是删除未经验证的“人类平均值”和本质化标签，把静态分数改为事件证据与趋势。

## 5. 可产品化能力地图

### A. 觉察

- 注意盲点
- 事实与解释分离
- 情绪和身体信号命名
- 记忆与原始记录对照
- 自动反应发现

### B. 选择

- 延迟反应
- 多角度生成
- 信息过滤
- 替代动作设计
- 不确定性标注

### C. 行动

- 小实验
- 边界表达
- 冲突沟通
- 习惯中断
- 环境调整

### D. 学习

- 预测与结果对照
- 重复模式聚类
- 反馈吸收
- 自我修正
- 新情境迁移

### E. 关系与系统

- 共情但不读心
- 个人与集体目标协调
- 角色、约束、信息源和反馈回路映射
- 信任证据与风险边界

## 6. 建议的核心数据结构

每条记录只保存可观察事实和用户自己的解释：

```text
Event
  context
  trigger
  observed_facts[]
  interpretation
  emotion_labels[]
  body_signals[]
  default_action
  intended_outcome
  actual_outcome
  alternative_action
  next_cue
  confidence
  source_refs[]
```

系统可以跨记录发现重复模式，但必须展示支持证据，让用户接受、修改或拒绝推断。

## 7. 证据等级

### 可作为反思候选

触发、解释、情绪、动作、结果、注意遗漏、记忆差异、信息来源、反馈和替代动作。这些是用户可以观察或核对的内容，但仍不是临床量表。

### 需要外部验证

所有“人类平均”“大部分人在 X%-Y%”、左右脑人格、神经传输机制、智商推断、健康效果和因果性陈述。未找到独立证据前不得进入评分、营销或建议。

### 仅限来源体系

神性、灵性结构、粒子、能量穴位、前世、催眠波、植入物和内部几何模块。若产品保留阅读模式，必须写成“作者体系认为”，且默认不参与任何算法。

### 禁止产品行为

- 诊断或治疗心理/身体疾病。
- 断言用户被植入、催眠、控制或遭受超自然影响。
- 用单一总分定义人的价值、意识水平或优劣。
- 给出自杀、严重创伤、急性疼痛等高风险情境的自动化替代治疗建议。
- 把用户日记用于广告定向或未经明确同意的模型训练。

## 8. 产品方向假设

语料最有潜力的商业化方向不是“玄学测评”或泛聊天机器人，而是一个面向高责任决策者和教练场景的 **Pattern Intelligence / Decision Debrief** 系统：

1. 用户在重要决策、冲突或压力事件后完成 3-5 分钟结构化复盘。
2. 系统把事实、解释、情绪、动作与结果分离。
3. 系统只从用户记录中提出带证据的重复模式候选。
4. 用户确认或拒绝模式，并为下一次设置可执行提示。
5. 周/月回顾显示哪些模式在什么情境出现、哪些替代动作真正改善结果。
6. 教练或团队版本只共享用户明确选择的摘要，不开放原始私密记录。

这个方向是否成立仍需市场、竞品、支付意愿、监管和开源技术验证。本文档只完成语料侧判断。

## 9. 知识产权边界

内部语料保留页码用于溯源。公开产品不应重新发布书中全文、插图、章节复刻或大量近似表达。产品应使用独立撰写的行为工作流、用户生成内容和经验证的公共证据；若要向客户直接提供原书内容，需要另行确认授权。

## 10. 生成物

- `corpus/index.json`：源文件、哈希、页数与覆盖率。
- `corpus/*/pages.jsonl`：逐页文本与页码。
- `corpus/*/toc.json`：原始 PDF 书签。
- `knowledge-base/summary.json`：章节统计、风险词和覆盖审计。
- `knowledge-base/concepts.jsonl`：概念候选。
- `knowledge-base/practices.jsonl`：练习上下文。
- `knowledge-base/claims.jsonl`：需审查主张。
- `knowledge-base/chapters/*.md`：按可靠页眉边界重组的九章全文。
