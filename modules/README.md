# Independent B/C source snapshots

These modules are archived source components, not integrations into the StillMind Web/Expo app. A remains in the repository root. No new B/C service is deployed by adding these directories.

- `B-wakeuphelper`: attributed Windows/.NET Framework 4.8 document-processing source. Personal defaults and stored speaker selections are removed. The private correction lexicon and book-reference dataset are intentionally absent.
- `C-knowledge-tools`: extraction, provenance, classification, deduplication and validation tools plus a schema. No book PDFs, page text, excerpts, generated knowledge records, embeddings, research snapshots or private conversations are bundled.

See `../docs/engineering/BC_ASSET_INVENTORY_2026-10-31.md` and the adjacent JSON manifest for scope, provenance, limitations and withheld categories. Historical documents under each module describe earlier local work; their tests, prices, market assumptions and permissions are not newly verified release claims.
